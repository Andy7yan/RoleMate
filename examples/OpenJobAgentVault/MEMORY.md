## Provenance conventions

Each fact identifies its source file and whether it is verified, user-asserted, inferred, unknown or deprecated.

## Rules for use and updates

Only `verified` and `user_asserted` facts may be used in applications. Generated wording and inferred information cannot be persisted without an explicit confirmation card.
